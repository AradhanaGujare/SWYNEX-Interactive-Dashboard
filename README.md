## Dataset
Cleaned Titanic passenger dataset from Tasks 1 and 2 (784 passengers).

## Tool Used
Google Data Studio (Looker Studio) with Google Sheets as the data source.

## KPIs
- Total Passengers: 784
- Average Age: 29.6
- Average Fare: 34.7
- Survival Rate: about 41%

## Charts
- Survival Rate by Sex
- Survival Rate by Passenger Class
- Survival Rate by Embark Town

## Filters
Drop-down filters for sex, passenger class and embark town. All KPIs and charts update when a filter is selected.

## Main Findings
- Women survived far more than men (about 74% vs 22%)
- First class passengers had the best survival rate (about 63%) and third class the lowest (about 26%)
- Passengers who boarded at Cherbourg had the highest survival rate
